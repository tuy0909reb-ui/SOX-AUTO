## 最終判断（先に）

### 採用: **B 2243 グローバルX 半導体 ETF**

（FORTRESS 成長局面＝ON袖の投入商品として）

**理由:**

1. **局面売買の約定性・売却速度が決定的に優れる**（取引時間内に逃げられる／投信のNAVラグがない）
2. **既存FORTRESSシグナル設計との相性が良い**（指数ベータ）。野村は同シグナルで **MaxDDが悪化**した実績がある
3. **透明性・再現性・オペ5秒判断・Discord通知との相性が高い**（指数・円建て・東証）

### 不採用（FORTRESS ON袖としては）: **A 野村世界半導体**

**理由:**

1. **約定ラグ**（申込〜NAV反映〜決済）がOFF判定の価値を削る
2. アクティブ集中がシグナル退出と衝突し、統合検証で **DD改善がマイナス**
3. 高コスト（信託報酬目安1.65%）＋集中（NVDA等高）が「局面判断α」より商品固有リスクを増やす

### 役割分離は合理的か → **Yes**

| 口座 / 用途 | 合理的な商品 |
|---|---|
| **NISA・長期保有** | **野村世界半導体**（期待値・アクティブ超過を非課税複利に載せる） |
| **FORTRESS・局面ON** | **2243**（シグナルに追従しやすい指数ベータ） |

```text
「長期保有なら野村 / 局面売買なら2243」は合理的。
むしろ同一商品を両用途に使うと、収益源泉と執行制約が混線する。
```

## 2. FORTRESS売買適性（最重要）

### 2.1 約定性

| 項目 | A 野村（公募投信） | B 2243（東証ETF） |
|---|---|---|
| 売買タイミング自由度 | **低**（受付締切・営業日制約） | **高**（取引時間中いつでも） |
| 注文→価格決定 | 原則 **その日の基準価額**（事後確定） | **板で即時** |
| 急落時の逃げ | **遅い**（当日中に逃げ切れない） | **相対的に速い**（成行/指値で退場可） |
| OFF判定の実効性 | シグナル当日に売れても、価格はNAVラグ | シグナル翌セッション約定モデルと整合しやすい |

**判定: 局面売買適性は B が明確に優位。**

### 2.2 再投入性能（ON復帰）

| シナリオ | 野村 | 2243 |
|---|---|---|
| ON判定日の翌営業日に投入 | 申込締切に間に合えば翌々日以降のNAV反映になりやすい | 翌営業日セッションで概ね取得可能 |
| 投信基準価額反映ラグ | **あり**（急反発の初動を取りこぼしやすい） | **なし**（市場価格で追従） |
| シグナルとの同期 | 弱い | 強い |

暴落後の「戻りの初動」を取る運用では、**NAVラグは構造的ハンデ**。

### 2.3 売却性能（OFF）

| 項目 | 野村 | 2243 |
|---|---|---|
| 即時売却 | **不可**（締切・NAV） | **取引時間内は可** |
| タイムラグ損失 | OFF後も翌NAVまでエクスポージャが残る | モデルどおり翌セッション退場に寄せられる |
| ギャップリスク | 両方ある | 両方ある（ETFも寄りで飛ぶ）が、**日中の追加悪化への反応速度が違う** |

**判定: OFFの実効性も B。** FORTRESSの防衛は「売れる速さ」に依存する。

## 5. 「長期なら野村／局面なら2243」分離評価

| 命題 | 評価 |
|---|---|
| NISAで野村を長期保有 | **合理的**（今回のNISA Decisionとも一致。期待値・超過を非課税に載せる） |
| FORTRESS ONで野村を使う | **不合理寄り**（執行ラグ＋シグナル相性不良） |
| FORTRESS ONで2243を使う | **合理的**（円建てSOXベータの運用面候補。履歴短は制約として残る） |
| 両方に同じ野村 | **非推奨**（役割混線。NISAの長期仮説とFORTRESSの退出速度が衝突） |

```text
推奨アーキテクチャ:
  NISA      = 野村（長期複利）
  FORTRESS  = 2243（局面ONベータ）± 既存Swing袖
```

2243の残リスク: **設定来が短く、2018/2022等のフルサイクル未経験**。  
定量の長期耐久は SOXX（USD）が厚い。円建て運用の実務解として2243を置き、SOXXを設計参照にするのが一貫する。

## 6. 結論フォーマット（依頼形）

**採用:** B 2243  

**理由:**

1. 局面ON/OFFの執行速度・約定性で野村を明確に上回る  
2. 固定シグナルとの統合検証で、野村はDD悪化・2243は少なくとも非劣後方向  
3. 透明性・再現性・オペ容易性がFORTRESS設計（人間＋Discord）に合う  

**不採用理由（FORTRESS ON袖としての野村）:**

1. NAVラグが防衛・再投入の両方を損なう  
2. アクティブ集中がシグナル退出と相性が悪い（DD悪化観測）  
3. 高コスト・低透明性が「局面判断α」を邪魔する  

**役割分離:**  
「長期保有なら野村／局面売買なら2243」は **合理的かつ推奨**。NISA Decision（野村1200）と矛盾せず、むしろ補完する。
