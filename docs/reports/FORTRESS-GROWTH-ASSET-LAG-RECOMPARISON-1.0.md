## 4. 追加確認

### 4.1 野村のアクティブ上振れは、遅延コストを上回るか？

- 共通窓BHでは野村が2243より高い（上振れは実在）。
- **ON/OFF + 現実ラグ（Model B）でも**、最終資産比ギャップ（野村/2243−1）= **3.98%**（野村優位）。
- 本窓に限れば、上振れは約定遅延コストを上回った。
- ただし往復2回のみのため、「常に上回る」とは言えない。長期窓では野村でもラグ加重（A→C）で成績・防御が劣化する。

### 4.2 NISAで野村を持つなら、FORTRESSも野村にすべきか？

**原則は否。** NISAは長期複利・執行不要で野村の超過を取りにいく口座。FORTRESSは退出・再投入の執行と通知が本体。商品統一の管理メリットより、役割混線コストが大きい。（定量最優先ならFORTRESS野村も検討余地あり、だが運用適性は劣る。）
