# Validation Maturity Level（Phase10-2）

仕様: `docs/specs/operational_validation_phase10_2.md`  
親文書: `docs/operational_validation.md`

---

## 1. Maturity Levels

```text
Level0  No Validation
Level1  Basic Monitoring
Level2  KPI Validation
Level3  Continuous Validation
Level4  Operational Excellence
```

---

## 2. 要件

* 成熟度は Validation Evidence / Frequency / Decision Gate の運用実態に基づく
* 自動昇格禁止。Human Review で評価する
* Service Level Validation（SLA → SLO → Operational Validation）と併用する
