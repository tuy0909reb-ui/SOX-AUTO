# Prediction Explainability（Phase9-4）

仕様: `docs/specs/predictive_aiops_research_phase9_4.md`  
親文書: `docs/predictive_aiops_research.md`

予測理由を説明可能にする研究を定義する。

---

## 1. Explainability Flow

```text
Prediction
    ↓
Evidence
    ↓
Trend
    ↓
Recommendation
```

---

## 2. 成果物

```text
Explainability Report
Prediction Trace Log
```

---

## 3. 原則

* Evidence / Trend なしの Recommendation を正式採用しない
* Trace は Research Audit と関連付ける
* Explainability 不足を理由に Human Review を省略しない
