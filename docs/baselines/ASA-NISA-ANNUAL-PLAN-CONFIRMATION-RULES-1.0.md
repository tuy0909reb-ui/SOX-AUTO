## 1. Purpose

翌年の NISA 成長枠計画を、迷わず立てられるようにする。  
部品説明で毎回止まらないよう、**確認の一本図と頻度**を固定する。

```text
目的: 翌年の「何を持つか」×「どう買うか」を11月に決める材料を揃える
やらない: 月次での商品自動入替 / 採用の自動変更
```

---

## 2. One picture（必ずこの順で説明する）

### 2.1 翌年計画の準備（Human向け・本線）

```text
① 市場動向確認
   ハイテク／半導体のままでよいか
   （対 S&P・NASDAQ・ハイテク、必要ならセクター相対）

② 投入アイテム確認
   メガ10／FANG+／ニッセイ／2243／野村 等を並べて決める

③ シリコンサイクルを踏まえた投入時期の確認
   問題なし → つみたて・成長とも年初一括
   後半下落など → 買い方を再設計
```

クレジット分割で載せる年は、**②が前月10日までに確定**している必要がある  
（例: 1月投入 → 12月10日）。だから①→②→③は **11月キック開始**が安全。

### 2.2 月次・満額後・ラベル

```text
【毎月】
  データ延長 → 当時の決め手の同じ比較を再適用
  → 向きが同じか／入れ替わったか（狭い監視。①②の本番ではない）

【枠満額後】
  場合により 1/5 利確 → 翌年買い直し（毎回必須ではない）

T3 / T4 は独立メーターではない。
①②の結果が物語を変えたときの判断ラベル。
```

| ラベル | 意味（Human） |
|---|---|
| T3 | 半導体枠の競争優位・役割が変わった → 枠内見直し |
| T4 | 「特定で制御できるから NISA に載せた」前提が弱い → FANG+ 復帰も必須比較 |

## 3. Cadence（忘れないための実行規則）

### 3.1 買い方前提（Human 2026-10-17）

| 枠 | シリコンサイクルに問題ないとき |
|---|---|
| **成長枠** | 年初一括（`ASA-NISA-GROWTH-BUY-METHOD-ANNUAL-LUMP-NISSAY-1.0`・2027〜） |
| **つみたて枠** | 基本・年初一括（`ASA-NISA-TSUMITATE-BUY-METHOD-ANNUAL-LUMP-1.0`。サイクル問題なしが前提） |

サイクル見通しが②（後半下落など）のときだけ、買い方を再設計する。

### 3.2 カレンダー（経路で締切が違う）

| When | What | Outcome |
|---|---|---|
| **毎月** | データ延長＋決め手の同じ比較 | 向き監視。採用変更しない |
| **毎年11月（キック開始）** | ①市場動向 → ②投入アイテム → ③投入時期 | 翌年計画ドラフト |
| **前月10日** | **クレジット分割払い**で載せる場合のハード締切 | **アイテム確定必須**（例: 翌年1月一括 → **12月10日**まで） |
| **12月中（通常）** | 現金・通常の年初一括のみの年 | 12月チェックでも翌年一括に間に合いうる |
| **T1/T2 発火時** | A を前倒し | 中間見直し |
| **T3/T4（Human）** | A＋必要なら FANG+ | 商品方針の再判断 |
| **枠満額後** | C を局面次第 | 必須ではない |

```text
つみたて・成長とも「サイクル問題なし → 年初一括」なら、
中身の判断自体は12月でも間に合うことがある。

ただしクレジット分割で載せる場合は、
**前月10日**までにアイテム確定が必要（Human運用制約）。
例: 1月に一括投入 → 12月10日がハード締切。
→ キックは11月開始のまま。分割経路の年は前月10日をハード締切にする。
```

## 8. Execution reminder（運用）

```text
每年10月末〜11月初（キック）:
  [ ] ① 市場動向（ハイテク／半導体のままでよいか）
  [ ] ② 投入アイテム確定（メガ／FANG／ニッセイ／2243／野村 等）
  [ ] ③ シリコンサイクル → 投入時期（年初一括か再設計か）
       問題なし → つみたて・成長とも年初一括前提
       問題あり → 買い方再設計
  [ ] 支払い経路
       クレジット分割 → ②を前月10日までに確定（例: 1月投入→12/10）
       現金・通常一括 → 12月中の確定でも間に合いうる
  [ ] T1/T2 状態（自動が来るまで手確認可）
  [ ] 翌年計画の Human 判断を残す
  [ ] 満額後なら 1/5 利確検討をするか決める

毎月:
  [ ] 月次ジョブ（延長＋決め手の同じ比較）が回ったか
```
