# Agent Collaboration Patterns（Phase9-1）

仕様: `docs/specs/ai_agent_collaboration_research_phase9_1.md`

協調モデル候補を整理し、利用目的・特徴・利点・制約を比較する。

---

## 1. Sequential

* 利用目的: 次の処理を前段の結果に依存させる
* 特徴: 一連の手順を順に実行し、出力を次へ渡す
* 利点: 構造化しやすく、境界侵害が起きにくい
* 制約: 反復や並列探索は効率が落ちる

---

## 2. Parallel

* 利用目的: 複数の観点から同時に探索・分析する
* 特徴: 複数 Agent が独立に処理し、合流する
* 利点: 対象の多面的検討が可能
* 制約: 合流点で責務混同リスクがあるため境界管理が必要

---

## 3. Hierarchical

* 利用目的: 上位で方針を与え、下位で分解実行する
* 特徴: 階層構造で役割を分担する
* 利点: 責務分離を保ちやすい
* 制約: 階層設計が不適切だと意図せず権限が拡張される

---

## 4. Coordinator

* 利用目的: 人間の指示を前提に、Agent間の調整を行う
* 特徴: Coordinator が実行判断の代替をせず、調整・ルーティングを担う
* 利点: Human Control を保ちつつ協調を成立させる
* 制約: Coordinator の責務設計が重要（Agent間の境界を侵害しない）
