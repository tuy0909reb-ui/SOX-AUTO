## 1. Types

```text
Preventive
Corrective
Adaptive
Perfective
```

| Type | 目的 |
|---|---|
| Preventive | 障害・劣化の予防 |
| Corrective | 発生した不具合の是正 |
| Adaptive | 環境・依存関係変化への適応維持 |
| Perfective | 運用継続のための整備（最適化・Adoption ではない） |

Perfective は Phase10-4 Optimization を意味しない。
